## Project Overview
This project analyzes arrival delay data for two airlines (ALASKA and AM WEST) across five destinations, as assigned in IS 362 Project 1.

## Files Included

### Core Files:
- `create_flight_data.py` - Creates the flight_data.csv file from the project specifications
- `flight_analysis.py` - Performs comprehensive analysis and generates reports
- `flight_data.csv` - The dataset (generated after running the scripts)
- `analysis_summary.txt` - Summary report (generated after analysis)

### Configuration:
- `requirements.txt` - Python package dependencies
- `README.md` - This documentation file

## Data Source
The data represents arrival delays for two airlines across five destinations:
- Los Angeles, Phoenix, San Diego, San Francisco, Seattle
